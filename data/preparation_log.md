# Data preparation log

Generated by `prepare_data.py` from the raw exports in `sources/data/`. Do not edit by hand.

**4,859 rows** in the working data. All three tables share `governorate`.

## Businesses (restaurants & cafes + other shops) — 3,419 rows

- `restaurants_cafes.csv`: 2,395 rows read, 2,395 kept.
- `other_shops.csv`: 1,024 rows read, 1,024 kept.
- Identical name + block + coordinates: 1 group(s) BASKIN ROBBINS block 346 (x2). **Kept**: units in one building can share coordinates, and they are separate registration records. Removing them would change published counts.
- Arabic duplicate columns (`l_sm`, `ltsnyf`, `ltsnyf_lfr_y`, `lmhfzt`) and the `location` column (a copy of the coordinates) dropped.
- `type` renamed to `category`: RESTAURANTS -> Restaurants & cafes, SHOPPING -> Shopping, HEALTH SERVICES -> Health services.
- Labels: governorate and subtype converted from UPPERCASE to Title Case (e.g. `CAPITAL` -> `Capital`, `COFFEE SHOPS` -> `Coffee Shops`) so they match the other datasets.
- `block` stored as a whole number (`346.0` -> `346`). No missing values in any column.
- **Limitation:** this is a registration snapshot (portal modified 2026-04-28). It has no opening or closing dates, so it may include businesses that have since closed.

## Land use — 1,120 rows

- 1,120 rows read, 1,120 kept.
- **Units:** `area` is published as text with the unit (`"16398662.168012 m2"`). The unit is stripped and the number stored in `area_m2`. Every row uses m2. The dashboard shows km2 (m2 / 1,000,000).
- **Missing values:** 1 row(s) have the unit but no number: Southern / Other / 2025-09. Kept with an empty `area_m2`: never filled in or estimated. Totals that include it say so, and a question about it is answered as not available.
- `year` + `month` (`2024`, `07 July`) combined into one sortable `period` (`2024-07`).
- **Stock, not flow:** each month is a full snapshot of land use. Never add months together; use one period (the latest, 2026-02, by default).
- Arabic duplicate columns and the `n` row counter dropped.

## Population — 320 rows

- 320 rows read, 320 kept. No missing values.
- **Boundary change:** `Central` and `Not Stated` appear only in 2010-06 and 2011-06 (Central (2010-06), Central (2011-06), Not Stated (2010-06), Not Stated (2011-06)). From 2012-06 the data has only the four current governorates, so their boundaries differ before and after. Kept as published; comparisons over time per governorate should start from 2012-06. (Background, not from these sources: the Central governorate was abolished in 2014.)
- Periods are mid-year (`YYYY-06`) for 2010-2025, plus year-end (`YYYY-12`) from 2022.
- `population` stored as a whole number. Arabic duplicate columns dropped.
